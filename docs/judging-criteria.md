# ハッカソン審査基準

このアプリの開発は、最終的に以下の基準を満たすことを目標とする。

## 1. 課題と解決策（10点）
- 誰のどんな課題を解くのかが伝わるか
- アプローチの納得感や独自性

## 2. プロダクト完成度（10点）
- メインの機能が動く状態まで完成しているか
- Cloudflare Workersにデプロイできているか

## 3. 技術チャレンジ（10点）
- Cloudflare開発者プラットフォームをどのように使ったか
- 新しい技術や実装に挑戦しているか
- 技術選定の意図が見えるか

## 4. プレゼン・熱量（10点）
- わかりやすく伝えられているか
- チームとしての取り組みが伝わるか
